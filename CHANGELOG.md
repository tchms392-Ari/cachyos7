# Changelog

## v1.0.0 - 2026-10-10
- First public release.
- Generic `cachyos7-apply`: works for any user, auto-detects the scale (1x/2x), only pins installed apps, and keeps lock/sleep at Xfce defaults unless `--no-lock`. `--logo` swaps the orb logo.
- Dark CachyOS-7 GTK3/GTK4 theme, CachyOS-7-Greeter, Aero xfwm4 theme in 1x and 2x, CachyOS-7 icons, CachyOS-7 sound theme.
- 4K/1440p/1080p wallpapers, plymouth theme, LightDM greeter config.
- `install.sh` / `uninstall.sh` with `--dry-run`, plus optional `--with-login` and `--with-splash` sudo steps with undo scripts.
